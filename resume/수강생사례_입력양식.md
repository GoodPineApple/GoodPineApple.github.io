# 수강생 사례 입력 양식

`teaching.html`(수강생 히스토리 페이지)에 넣을 사례를 이 양식으로 채워 주세요.
아래 **작성 예시**가 이미 페이지에 반영된 ConnecTone 사례입니다. 같은 형식으로 이어서 쓰면 됩니다.

- `[비공개]` 표시 항목은 페이지에 나가지 않습니다. 귀속 확인과 사실 검증용입니다.
- 문장으로 안 쓰셔도 됩니다. 키워드만 적어 주시면 제가 문장으로 다듬습니다.
- 모르는 항목은 비워 두세요. 비면 그 단계는 페이지에서 생략합니다.

---

## A. 풀 스토리형 (타임라인으로 크게 소개)

한 페이지에 3~4개가 적당합니다. 변화의 낙차가 큰 분을 고르면 좋습니다.

```
### 사례 N

[비공개] 수강생 구분      :
[비공개] 기수             : 1기 / 4기 / 그 외
[비공개] 공개 동의        : 받음 / 안 받음 / 학교 페이지에 이미 공개됨
[비공개] 학교 공식 페이지 노출 여부 : O / X

공개 호칭        : 실명 대신 쓸 표현 (예: 보컬리스트 출신 수강생)
서비스명         :
한 줄 정의       : 무엇을 해 주는 서비스인가
서비스 URL       : (없으면 비움 / 있어도 비공개 원하면 "비공개"라고)

1) 출발점
   - 원래 직업·배경  :
   - 개발 경험 수준  :
   - 초반에 겪은 것  : (막힌 지점, 태도, 인상적인 장면)

2) 아이템 변천  ※ 몇 개든 상관없습니다
   - 1차 아이템 :            / 접은 이유 :
   - 2차 아이템 :            / 접은 이유 :
   - 3차 아이템 :            / 접은 이유 :

3) 피벗의 계기
   - 무엇을 깨달았나 :
   - 그 깨달음이 어디서 왔나 : (사용자 반응, 본인 경험, 시장 확인 등)

4) 최종 서비스
   - 핵심 기능 1~3 :
   - 이 사람이라서 가능했던 강점 :

5) 성과
   - 내용 : (선정·수상·사용자수·매출·투자·취업 등)
   - 시점 :

6) 강사 코멘트
   - 내가 한 역할 한 줄 :
```

## B. 카드형 (이름과 한 줄만 짧게)

스토리까지는 없지만 이름은 남기고 싶은 결과물용입니다.

```
서비스명 / 한 줄 정의 / [비공개] 기수 / [비공개] 학교 페이지 노출 O·X / URL(선택)
```

예시:
```
FLOWMATE / 정부지원사업을 찾고 맞춰 보고 사업계획서 작성까지 이어 주는 서비스 / 1기 / O / mate.flow-coder.com
```

## 작성 예시 (현재 페이지에 반영된 사례)

```
### 사례 1

[비공개] 수강생 구분      : (내부 식별용)
[비공개] 기수             : 1기
[비공개] 공개 동의        : 별도 연락 예정
[비공개] 학교 공식 페이지 노출 여부 : O

공개 호칭        : 보컬리스트 출신 수강생
서비스명         : ConnecTone
한 줄 정의       : AI를 통한 내 음악 분석 피드백 및 레슨 중계 서비스
서비스 URL       : https://www.connect-tone.com/

1) 출발점
   - 원래 직업·배경  : 무대에서 노래하던 보컬리스트
   - 개발 경험 수준  : 전무, 터미널도 처음
   - 초반에 겪은 것  : 코드보다 "내가 이걸 할 수 있는가"와 싸우는 시간

2) 아이템 변천
   - 1차 아이템 : 사이버 노인정      / 접은 이유 : 본인이 매일 겪는 문제가 아니었음
   - 2차 아이템 : 악기 중고거래 플랫폼 / 접은 이유 : 배포까지 했으나 거래는 이미 기존 중고 플랫폼에서 일어나고 있었음

3) 피벗의 계기
   - 무엇을 깨달았나 : 음악 하는 사람들이 원하는 건 거래가 아니라 "내 실력이 지금 어느 정도인가"에 대한 답
   - 그 깨달음이 어디서 왔나 : 악기 거래 서비스를 실제로 만들어 보고 시장을 확인하면서

4) 최종 서비스
   - 핵심 기능 : 음악 업로드 → AI 분석·피드백 → 레슨 중계
   - 이 사람이라서 가능했던 강점 : 10년 넘게 노래해 온 사람만 아는 평가 기준을 제품에 반영

5) 성과
   - 내용 : 모두의 창업 1기 선정, 사업화 진행 중
   - 시점 : 수료 이후

6) 강사 코멘트
   - 내가 한 역할 : 코드를 알려 준 게 아니라, 만들어 보고 아니면 접는 사이클을 세 번 돌 수 있게 속도를 붙여 준 것
```
